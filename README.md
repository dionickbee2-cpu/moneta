# 💰 Moneta — учёт расходов в Telegram с ИИ

Telegram-бот и мини-приложение для учёта расходов и доходов. Данные хранятся в Google Sheets, ИИ-функции работают на Claude.

- **Бот:** пишете `кофе 4.5` или `зарплата +3411`, выбираете категорию кнопкой. Есть статистика, бюджеты, напоминания, выгрузка в CSV и Excel.
- **Мини-приложение** (`docs/index.html`): графики, операции, счета, а также:
  - 📷 **Импорт скринов** из Revolut, Sparkasse и других банков. ИИ распознаёт операции, даты и категории и отмечает переводы между своими счетами и возможные дубли. Вы проверяете список и сохраняете.
  - 🦊 **Финн** — чат с ИИ о ваших тратах: где перерасход и что можно оптимизировать.

## Структура

| Файл | Что делает |
|------|------------|
| `main.py` | Точка входа: запускает бота и API (waitress) в одном процессе |
| `bot.py` | Команды и сообщения бота, планировщик уведомлений |
| `api.py` | Flask API для мини-приложения (авторизация через Telegram initData) |
| `storage.py` | Работа с Google Sheets: по листу `user_<id>` на пользователя |
| `ai.py` | Claude: распознавание скринов и чат, дневные лимиты |
| `docs/index.html` | Мини-приложение (GitHub Pages) |
| `tests/` | pytest с поддельной таблицей в памяти |

## Переменные окружения

| Переменная | Обязательна | Описание |
|------------|:-----------:|----------|
| `TELEGRAM_TOKEN` | ✅ | Токен бота от @BotFather |
| `GOOGLE_CREDS_JSON` | ✅ | JSON-ключ сервисного аккаунта Google (содержимое файла одной строкой) |
| `ANTHROPIC_API_KEY` | ✅ для ИИ | Ключ Claude API (console.anthropic.com) |
| `WEBAPP_URL` | — | Адрес мини-приложения; без него в боте нет кнопки «Открыть приложение» |
| `SPREADSHEET_NAME` | — | Название таблицы (по умолчанию `Finance Bot Data`) |
| `CLAUDE_MODEL` | — | Модель (по умолчанию `claude-sonnet-5`; точнее, но дороже — `claude-opus-5`) |
| `BOT_TIMEZONE` | — | Часовой пояс (по умолчанию `Europe/Berlin`) |
| `REMINDER_HOUR`, `REMINDER_MINUTE` | — | Время напоминания по умолчанию и итогов недели (20:00) |
| `MAX_USERS` | — | Максимум пользователей, то есть листов в таблице (300) |
| `AI_DAILY_IMPORTS` | — | Скринов в день на пользователя (30) |
| `AI_DAILY_CHATS` | — | Сообщений Финну в день на пользователя (40) |
| `ALLOWED_ORIGIN` | — | CORS-источники через запятую (по умолчанию `*`; защита — подпись initData) |
| `SESSION_SECRET` | — | Секрет для подписи личных ссылок; по умолчанию выводится из `TELEGRAM_TOKEN` (смена токена отключает все ссылки) |
| `DEV_USER_ID` | — | **Только для локальной отладки:** API пускает запросы без Telegram как этого пользователя. На проде не задавать! |

## Настройка Google Sheets

1. В [Google Cloud Console](https://console.cloud.google.com) включите **Google Sheets API** и **Google Drive API**.
2. Создайте сервисный аккаунт, затем в разделе Keys → Add Key → JSON скачайте ключ.
3. Создайте таблицу с названием из `SPREADSHEET_NAME` и дайте `client_email` из ключа права «Редактор».
4. Содержимое JSON вставьте в переменную `GOOGLE_CREDS_JSON`. Сам файл в git не коммитьте (он есть в `.gitignore`).

Колонки листа: `Date, Amount, Category, Description, Type, Month, UserID, TxID, Account, Source`. Старые листы, в том числе с русскими заголовками, дополняются недостающими колонками автоматически.

## Запуск локально

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt -r requirements-dev.txt   # Windows
python -m pytest -q        # тесты
python main.py             # бот + API на http://localhost:8000
```

Мини-приложение локально: `python -m http.server -d docs 8765`, затем откройте
`http://localhost:8765/index.html?api=http://localhost:8000`. Параметр `?api=` работает только на localhost. Для API без Telegram задайте `DEV_USER_ID`.

## Деплой

- **API и бот:** Railway, пуш в `main` запускает деплой. Команда запуска — `python main.py` (см. `Procfile`).
- **Мини-приложение:** GitHub Pages из папки `docs/`. Адрес API зашит в `docs/index.html` (`PROD_API`).
- После деплоя проверьте `https://<домен>/health`: там должно быть `sheets_connected: true`.

## Отдельное приложение (без Telegram)

Moneta можно установить на экран «Домой» как обычное приложение (PWA):
- в мини-аппе: ⚙ → **«Установить как приложение»**, откроется браузер с личной ссылкой;
- или команда боту **`/app`**.

Ссылка содержит подписанный ключ (`sessions.py`, HMAC от `SESSION_SECRET` или `TELEGRAM_TOKEN`), действующий 180 дней.
`/logoutall` отзывает все выданные ссылки. На iPhone ключ хранится в адресе (`#t=…`): iOS копирует в приложение
на экране «Домой» только URL, поэтому в `manifest.webmanifest` нарочно нет `start_url`.

## Команды бота

`/stats [ГГГГ-ММ]`, `/compare`, `/finn вопрос`, `/last`, `/find запрос`, `/budget категория лимит`,
`/settings ЧЧ:ММ`, `/export`, `/exportxls`, `/app`, `/logoutall`, `/deletedata`.

Уведомления: ежедневное напоминание в выбранное время, итоги недели по воскресеньям, отчёт за прошлый месяц 1-го числа в 10:00.
